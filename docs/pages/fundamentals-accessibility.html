Fundamentals

Accessibility

Components follow the WAI-ARIA authoring practices: native elements where possible, one tab stop per composite control, visible focus, reduced motion.

Names

  • Fields use label. Without a visible label, set aria-label-text.
  • Icon-only buttons need label; kern-tooltip only adds a visible hint.
  • kern-icon is decorative unless it has a label.

Announcements

  • kern-alert tone="danger" and kern-toast tone="danger" are alerts; the others are polite.
  • kern-skeleton is hidden from assistive technology: set aria-busy="true" on the loading container.
  • While a modal dialog is open everything outside is inert. Toasts shown then are neither clickable nor announced; close the dialog first.

Motion

Animations (drawer, toasts, skeleton shimmer, chevrons) stop under prefers-reduced-motion.
