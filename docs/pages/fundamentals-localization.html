Fundamentals

Localization

Formats come from Intl; texts are properties. Default texts are German, because Kern started in a German-speaking homelab.

Locale

Components that format dates, times, numbers or sizes take a locale (BCP 47). Without it they use <html lang>, then the browser language.

Texts

Every visible or announced text is a property starting with label, e.g. label-close on kern-dialog, label-invalid on typed fields, label-range on kern-pagination. Placeholders like {n} or {name} are replaced. The property tables on each component page list them.

<kern-pagination total="380" label-range="{from}–{to} of {total}" label-next="Next page"></kern-pagination>
