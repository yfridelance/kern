Fundamentals

Layout

Content has a maximum width, cards and tiles sit in a kern-grid, and breakpoints are measured on the container, not on the window.

Tokens

Widths for the page and the sidebar, and three breakpoints. Custom properties do not work in @media or @container conditions, so the breakpoint values are written literally there; the tokens are for documentation and for JavaScript (getComputedStyle(document.documentElement).getPropertyValue('--breakpoint-md')).

Breakpoints

Kern components switch by the room they really have: kern-grid is a size container, and its columns and the spans of kern-grid-item change at 640, 960 and 1280 px of grid width. A grid in a sidebar, a drawer or half a page therefore behaves like on a small screen, without any extra configuration. Use the same values for your own container queries.

.panel { container-type: inline-size; } @container (min-width: 640px) { .panel .fields { grid-template-columns: 1fr 1fr; } }

Grid

kern-grid has two modes:

  • Auto (default): as many columns of at least min as fit, e.g. for key figures or device cards. No breakpoints needed.
  • Columns: columns="12" with kern-grid-item span="12" span-md="8" for layouts like list and details side by side.
<kern-grid min="220px"> <kern-stat label="Devices online" value="36"></kern-stat> <kern-stat label="Updates" value="3"></kern-stat> </kern-grid> <kern-grid columns="12"> <kern-grid-item span="12" span-md="8"><kern-card heading="Devices">…</kern-card></kern-grid-item> <kern-grid-item span="12" span-md="4"><kern-card heading="Details">…</kern-card></kern-grid-item> </kern-grid>

Gaps come from the spacing scale (gap="sm|md|lg"); inside a card, use kern-grid too, not nested cards.
