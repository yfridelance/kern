Kern

Dark-first web components for self-hosted tools around device management, monitoring, networks and smart homes. Built with Stencil and Shadow DOM, without runtime dependencies. Light is a complete second theme.

What you get

  • 59 elements: layout, navigation, forms (form-associated, with validation), date and time, feedback, data display.
  • One set of tokens for colours, type and spacing. Dark and light come from the same tokens.
  • Accessible by default: keyboard patterns after WAI-ARIA, labels, focus rings, reduced motion.
  • Framework-free, with generated Angular wrappers and value accessors.
