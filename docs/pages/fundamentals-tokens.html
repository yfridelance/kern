Fundamentals

Colour tokens

Every colour in Kern is a CSS custom property with a value per theme. The source is tokens/tokens.json; kern.css is generated from it.

Roles

  • Surfaces: canvas (page), surface (cards, tables), surface-raised (dialogs, popovers), surface-sunken (fields, code), hover
  • Lines: line for separators, line-strong for field borders
  • Text: text, text-muted (secondary), text-faint (placeholders, disabled)
  • Accent: accent (primary buttons, selection), accent-soft (backgrounds), accent-text (links, active text), on-accent (text on accent)
  • Status: ok, warn, danger and their -soft backgrounds
  • Other: focus (focus rings), scrim (behind modals), json-* (code highlighting), chart-* (data series)

All colours

The swatches show both themes at once, independent of the theme you are viewing.

Shadows

--shadow-overlay is used for popovers, menus, toasts and dialogs.
