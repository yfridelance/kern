Fundamentals

Forms

All input components are form-associated (ElementInternals): they take part in <form> like native fields.

What works like native fields

  • name puts the value into FormData. Components with several values (kern-select multiple, kern-file-input multiple) add one entry per value.
  • required blocks submitting while empty; form.reset() restores the initial value; a disabled <fieldset> disables the fields.
  • kern-button type="submit" / type="reset" submit or reset the surrounding form.

Errors

Set error to show a message. A field with error is invalid and blocks submitting until the message is removed. Typed fields (dates, IPs, MACs, numbers, colours) also report their own problems, e.g. «Not a valid IPv4 address».

Events

  • kernChange with { value }: the value was applied. For typed fields this is on Enter or when leaving the field; for controls on every change.
  • kernInput: on every keystroke or while dragging (where offered).

Normalised values

Typed fields accept several notations and store one: kern-ip-input («192.168.1.10 - 50» → 192.168.1.10-192.168.1.50), kern-mac-input (any notation → C8:2B:96:1A:3F:00), kern-date-picker (locale text → ISO 2026-10-19), kern-color-picker (#3CC → #33cccc).

Angular

The generated value accessors connect ngModel and reactive forms: text accessor for most fields, number accessor for kern-rating and kern-step-input, boolean accessor for kern-switch and kern-checkbox. kern-file-input has none; use (kernChange).
